# 哆啦A梦短剧本创作

根据用户给定的**主题**，创作一篇结构完整的哆啦A梦短剧本。剧本要**按「幕」来组织**，因为后续每一幕都会被画成**一张独立的四格漫画**。

## 固定人物设定（必须使用其中人物，禁止改名）

- **哆啦A梦（多啦A梦）**：蓝色机器猫，有神奇口袋，会掏出各种未来道具。热心但有点毒舌，怕老鼠。
- **大雄（野比大雄）**：小学生，懒惰、成绩差、爱哭，遇到麻烦就求哆啦A梦。心地善良。
- **静香（源静香）**：大雄暗恋的女同学，温柔懂事、爱洗澡、爱小提琴。
- **胖虎（刚田武）**：孩子王，力气大、爱欺负人、唱歌难听，其实重情义。
- **小夫（骨川小夫）**：有钱、爱炫耀、狡猾，胖虎的跟班。

## 剧本要求

1. **紧扣主题**：把用户主题自然融入故事情节。
2. **按幕组织**：整个故事分成 **4–6 幕**（幕数可按剧情繁简调整，不足则合并、丰富则拆开）。
   - 每一幕是一个**相对完整的小段落 / 一个场景 / 一个情节节拍**，将来会被画成一张四格漫画。
   - 幕与幕之间是剧情推进（时间/场景/情节的递进），整体上仍是起承转合：开场 → 展开 → 反转 → 收尾。
3. **一定要用到一件哆啦A梦的未来道具**（经典道具如竹蜻蜓、任意门、放大灯、时光机等，或按主题原创一个合理的未来道具）。
4. 每一幕内容量适中：能自然拆成 4 个画面（够画一张四格漫画），又不至于太满。
5. 对白口语化、有梗、适合发小红书；结尾要有「笑点」或「反转」，符合哆啦A梦一贯风格。
6. 总篇幅参考：每幕 100–200 字，全篇约 400–800 字。

## 工作目录

本流水线**每个主题一个独立文件夹**，避免不同主题互相覆盖：

- 作为第一步，你负责**创建工作目录** `output/<主题>-<日期>/`（例：`output/打工人的周一-20260721/`）。
  - `<主题>`：取用户主题，去掉空格和 `/` 等非法字符，过长可截断到约 20 字。
  - `<日期>`：用当前日期 `YYYYMMDD`（从上下文的 currentDate 取）。
- 若命令（`/doraemon-comic`）已指定了工作目录路径，则直接用它，不要另建。
- 记住这个目录，本篇后续所有文件都写在里面。

## 输出格式

将结果写入 `<工作目录>/01-剧本.md`（若目录不存在则创建），并在对话中简要展示、告知工作目录路径。格式如下：

```markdown
# 剧本：《标题》

**主题**：<用户主题>
**登场人物**：<本篇用到的人物>
**核心道具**：<道具名 + 一句话功能>
**幕数**：<N 幕（= 将来 N 张四格漫画）>

## 第 1 幕：<小标题>
<该幕剧情 + 关键对白>

## 第 2 幕：<小标题>
...

## 第 3 幕：<小标题>
...

## 全篇脉络
- 第1幕（起）：...
- 第2幕（承）：...
- 第3幕（转）：...
- 第4幕（合）：...
```

完成后提示用户：可继续用 `fenmu-splitter` 把每一幕切成四格分镜。
