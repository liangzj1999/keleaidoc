# 小红书发布文案生成

为已完成的哆啦A梦四格漫画生成一套**可直接复制发布**的小红书文案，最大化点击与互动。

## 工作目录

本篇所有文件都在同一个工作目录 `output/<主题>-<日期>/` 下。命令指定了就用指定的；否则默认选 `output/` 下**最近修改**的那个子文件夹继续写。

## 输入

综合读取 `<工作目录>/01-剧本.md`、`<工作目录>/02-分幕.md`（若存在）了解故事内容与主题。若都不存在，用对话中的信息或询问用户。

## 先定语气流派

先根据剧情基调选一个语气，全篇文案统一风格：
- **软萌治愈系**：今天也被哆啦A梦治愈到了呜呜呜～大雄这个笨蛋怎么这么可爱🥺
- **发疯共鸣系**：啊啊啊这不就是我本人吗！！！我需要一个哆啦A梦!!!!🤯
- **搞笑吐槽系**：笑死，大雄又把好道具用来摆烂了，这含金量还在上升💀

## 输出内容（五部分）

### 1. 标题（给 5 个备选）
- 20 字以内，符合小红书爆款风格：情绪钩子 / 悬念 / 数字 / 反差 / emoji。
- 例：`哆啦A梦如果有这个道具，我愿意上班🥹`

### 2. 正文描述
- 100-200 字，第一人称、口语化、有代入感，语气贴合上面选的流派。
- 开头一句抓人，简述这组四格漫画讲了啥（说明是 N 张连载/轮播四格漫画，不剧透结局，留钩子），结尾引导互动（点赞/评论/投票）。
- 适当穿插 emoji，分行排版清爽。

### 3. 话题标签 Tag
- 给 8-12 个 `#标签`，混合：IP 相关（#哆啦A梦 #机器猫 #大雄）、内容形式（#四格漫画 #AI绘画 #原创漫画）、主题相关（按主题定）、流量话题（#每日一画 #治愈系 等）。

### 4. BGM 推荐
- 推荐一首贴合剧情/情绪的背景音乐：**歌名 + 歌手 + 一句推荐理由**（哆啦A梦主题曲、治愈日系、或应景热歌均可）。

### 5. 投票选项（小红书互动投票）
- 设计 1 个与剧情/主题强相关的投票，给出**投票问题 + 2-4 个选项**。
- 选项要有趣、能引发站队或表达欲。
- 例：问「你最想要哆啦A梦的哪个道具？」→ 任意门 / 竹蜻蜓 / 时光机 / 记忆面包。
