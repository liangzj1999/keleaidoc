# 哆啦A梦四格漫画工作室

一套用 Claude Code 把「一个主题」变成「一组哆啦A梦四格漫画 + 小红书发布文案」的技能集合。

## 🚀 快速开始

一键生成（推荐）：

```
/doraemon-comic 打工人的周一早晨
```

系统会依次完成：写剧本 → 分幕切四格 → 生图提示词 → 小红书文案，每步先展示再进入下一步。

## 核心结构：两层

```
一篇剧本
  ├─ 第 1 幕  →  一张四格漫画（Panel 1-4）
  ├─ 第 2 幕  →  一张四格漫画（Panel 1-4）
  └─ 第 N 幕  →  一张四格漫画（Panel 1-4）
```

- 剧本先切成 **N 幕**（一般 4-6 幕）。
- **每一幕单独画成一张四格漫画**，该张图内部才是 Panel 1-4。
- 有几幕就出几张四格漫画，不是整篇只有 4 格。

## 可用技能

| 技能 | 作用 | 输入 → 输出 |
|---|---|---|
| `/doraemon-comic` | 一键串联全流程 | 主题 → 4 个文件 |
| `juben-writer` | 剧本生成器（按幕组织） | 主题 → `01-剧本.md` |
| `fenmu-splitter` | 分幕 + 每幕切四格分镜 | 剧本 → `02-分幕.md` |
| `doraemon-image-prompt` | 每幕一张四格漫画的生图提示词 | 分镜 → `03-生图提示词.md` |
| `xiaohongshu-post` | 小红书标题/正文/tag/BGM/投票 | 剧情 → `04-小红书文案.md` |

单步执行也可以，例如直接说「用哆啦A梦主题写个减肥的剧本」会自动触发 `juben-writer`。

## 固定人物（禁止改名/换 IP）

哆啦A梦、大雄（野比大雄）、静香（源静香）、胖虎（刚田武）、小夫（骨川小夫）。
各张图之间人物形象需保持一致——生图提示词技能里内置了每个角色的英文外观基准表。

## 生图提示词约定

- **画面描述用英文，气泡台词保留中文**：`speech bubble with text: "中文台词"`（生图模型写中文更准）。
- 每张图一个 ` ```text ` 代码块，带统一风格后缀（藤子·F·不二雄画风），方便一键复制到 Midjourney / 即梦 / SD。
- 比例 3:4（竖版适合小红书），另附「对白清单」方便后期手动加字。

## 产物管理（output/）

**每个主题一个独立文件夹**，互不覆盖：

```
output/
└── 打工人的周一-20260721/
    ├── 01-剧本.md
    ├── 02-分幕.md
    ├── 03-生图提示词.md
    └── 04-小红书文案.md
```

- 文件夹名 = `<主题>-<日期YYYYMMDD>`。
- 单独用某个 skill 时，下游默认接着 `output/` 下**最近修改**的文件夹写。
- `output/` 已在 `.gitignore` 中忽略（产物是生成物，不进版本库）。

## 项目结构

```
CLAUDE.md

.claude/

    doraemon-comic.md                      # 一键串联 command
  skills/
    juben-writer/SKILL.md                  # 剧本
    fenmu-splitter/SKILL.md                # 分幕 + 四格分镜
    doraemon-image-prompt/SKILL.md         # 生图提示词
    xiaohongshu-post/SKILL.md              # 小红书文案
output/                                     # 生成产物（gitignore）
```
