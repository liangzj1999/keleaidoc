# Chiikawa 漫画一站式生成

请告诉我你的【主题】或【联名IP】是什么？

## 自动判断逻辑

收到用户输入后，自动判断类型：

### 判断规则
- **联名IP**：知名的动漫/游戏/影视作品名称（如：名侦探柯南、哈利波特、原神、鬼灭之刃、龙珠、进击的巨人等）
- **普通主题**：其他所有关键词（如：露营、减肥、失眠、猫咪、下雨天等）

## 流程

### 如果是普通主题：

1. 调用 `/chiikawa-script` 生成分镜脚本
   - 输入：用户提供的主题
   - 输出：封面 + 6张四格漫画的分镜脚本（含对白气泡标注）

2. 调用 `/chiikawa-prompt` 生成英文提示词
   - 输入：上一步的分镜脚本
   - 输出：7个英文提示词代码块（含气泡框）

3. 调用 `/chiikawa-xiaohongshu` 生成小红书文案
   - 输入：用户提供的主题
   - 输出：标题 + 正文 + 标签 + BGM + 投票

### 如果是联名IP：

1. 调用 `/chiikawa-crossover` 生成联名剧本
   - 输入：用户提供的IP名称
   - 输出：8-12个分镜的短漫剧本

2. 调用 `/chiikawa-prompt` 生成英文提示词
   - 输入：上一步的分镜脚本
   - 输出：英文提示词代码块（含气泡框）

3. 调用 `/chiikawa-xiaohongshu` 生成小红书文案
   - 输入：用户提供的IP名称
   - 输出：标题 + 正文 + 标签 + BGM + 投票

## 完成标记

全部完成后，输出：

✅ **Chiikawa 漫画生成完成！**

**类型：** [普通主题 / 联名IP]
**输入：** [用户输入的内容]

**生成内容：**
- ✓ 分镜脚本（[X]个分镜，含气泡标注）
- ✓ 英文提示词（[X]个代码块，含气泡框）
- ✓ 小红书文案（标题+正文+标签+BGM+投票）
