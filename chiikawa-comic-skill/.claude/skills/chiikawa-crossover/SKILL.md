# Chiikawa 跨界联名编剧

创作 Chiikawa 三小只与指定 IP 角色互动的四格漫画剧本，强调逻辑错位与降维解构的幽默感。

## 角色设定

| 角色 | 性格特点 |
|------|----------|
| 吉伊 | 胆小爱哭，容易受惊，但很善良 |
| 小八 | 天真活泼，喜欢解说，话比较多 |
| 乌萨奇 | 混沌不可控，行为难以预测 |

## 幽默感技巧

### 1. 日常化消解
IP 里最牛的角色，在这里可能只是个理发师、讨伐对象，或者被当作除草机。

### 2. 无效的帅气
IP 角色试图耍帅，但因为 Chiikawa 的身体比例或道具问题，变得极其滑稽。

### 3. 沟通的黑洞
IP 角色在讲大道理/走剧情，三小只完全听不懂，只关心"能不能吃"或者"这个能不能拿来玩"。

### 4. 细思极恐的可爱
表面看很可爱，仔细一想这个互动其实很残酷或很黑暗（Chiikawa 原作特有的风味）。

## 创作要求

1. **篇幅**：1张封面 + 6张四格漫画（和普通主题保持一致）
2. **角色在场**：三小只必须都在，但不需要每个人都发疯
3. **性格一致**：吉伊胆小爱哭、小八天真解说、乌萨奇混沌不可控
4. **画面感优先**：重点描写表情细节（豆豆眼、死鱼眼、流汗、颤抖、突然的高画质）
5. **剧情连贯**：6张四格漫画要讲一个完整的故事，有起承转合
