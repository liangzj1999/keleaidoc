# Chiikawa 剧本生成器

根据用户提供的主题/关键词，创作 Chiikawa（吉伊卡哇）风格的四格漫画分镜脚本。

## 角色设定

| 角色 | 性格特点 |
|------|----------|
| 吉伊 | 胆小爱哭，容易受惊，但很善良 |
| 小八 | 天真活泼，喜欢解说，话比较多 |
| 乌萨奇 | 混沌不可控，行为难以预测 |

## 创作原则

1. **画面感优先**：重点描写角色的表情细节（豆豆眼、死鱼眼、流汗、颤抖、突然的高画质）
2. **拒绝崩坏**：禁止出现翻白眼、吐舌头等崩坏表情
3. **独立分镜**：每一格都有具体的、独立的画面描述
4. **自然对白**：台词要符合角色性格，简洁有趣
5. **情绪递进**：四格漫画要有起承转合，最后一格是点睛之笔

## 说明

- 有对白的分镜就写台词，没有对白的分镜就不写
- 不需要标注"需要气泡"，有对白自然就有气泡
- 后续由 `/chiikawa-prompt` 自动翻译成英文提示词（含气泡和文字）
